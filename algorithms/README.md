# Algorithms 🧮

Esta carpeta contiene soluciones a problemas de algoritmos de HackerRank.

## Subcategorías

### Warmup
Problemas de calentamiento ideales para comenzar. Generalmente son problemas simples que te ayudan a familiarizarte con la plataforma.

**Dificultad:** Easy  
**Temas:** Operaciones básicas, bucles, condicionales

### Implementation
Problemas que se enfocan en implementar una solución directa al problema planteado.

**Dificultad:** Easy a Medium  
**Temas:** Lógica, simulación, iteración

### Strings
Problemas relacionados con manipulación y procesamiento de cadenas de texto.

**Dificultad:** Easy a Hard  
**Temas:** Búsqueda de patrones, manipulación de texto, palíndromos, anagramas

### Sorting
Algoritmos de ordenamiento y problemas relacionados.

**Dificultad:** Easy a Hard  
**Temas:** QuickSort, MergeSort, Counting Sort, ordenamiento personalizado

### Search
Algoritmos de búsqueda.

**Dificultad:** Easy a Hard  
**Temas:** Binary Search, búsqueda lineal, búsqueda en matrices

### Dynamic Programming
Programación dinámica - uno de los temas más desafiantes pero fundamentales.

**Dificultad:** Medium a Hard  
**Temas:** Memoization, tabulation, problemas de optimización

### Greedy
Algoritmos voraces que toman decisiones localmente óptimas.

**Dificultad:** Medium a Hard  
**Temas:** Problemas de selección, optimización, scheduling

### Graphs
Teoría de grafos y algoritmos relacionados.

**Dificultad:** Medium a Hard  
**Temas:** BFS, DFS, Dijkstra, árboles de expansión mínima

## Consejos

1. **Empieza por Warmup** si eres principiante
2. **Lee el problema cuidadosamente** antes de codificar
3. **Piensa en la complejidad** de tu solución
4. **Prueba con casos edge** antes de enviar
5. **Revisa las soluciones de otros** después de resolver
