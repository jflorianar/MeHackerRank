## Libros Recomendados

### Para Principiantes

#### "Python Crash Course" - Eric Matthes
- Introducción práctica a Python
- Incluye proyectos reales
- Ideal para comenzar

#### "Automate the Boring Stuff with Python" - Al Sweigart
- Disponible gratis online: https://automatetheboringstuff.com/

- 189 problemas de programación
- Estrategias de entrevista

- El libro de referencia definitivo
- Nivel universitario
- Muy completo pero denso

#### "Grokking Algorithms" - Aditya Bhargava
- Explicaciones visuales
- Fácil de entender
- Ideal para principiantes

### Para Python Avanzado

#### "Fluent Python" - Luciano Ramalho
- Python idiomático
- Conceptos avanzados
- Para desarrolladores intermedios-avanzados

#### "Python Cookbook" - David Beazley
- Recetas de código
- Soluciones a problemas comunes
- Referencia práctica

#### "Effective Python" - Brett Slatkin
- 90 mejores prácticas
- Código más pythonico
- Nivel intermedio

## Recomendación de Ruta de Aprendizaje

### Nivel Principiante (0-3 meses)
1. Completar un curso básico de Python
2. Resolver problemas Easy en HackerRank
3. Leer "Python Crash Course" o "Automate the Boring Stuff"

### Nivel Intermedio (3-6 meses)
1. Resolver problemas Medium en HackerRank/LeetCode
2. Estudiar estructuras de datos básicas
3. Leer "Grokking Algorithms"
4. Empezar proyectos personales

### Nivel Avanzado (6-12 meses)
1. Resolver problemas Hard
2. Estudiar algoritmos avanzados
3. Participar en competencias
4. Contribuir a proyectos open source
5. Leer "Cracking the Coding Interview"

---

**Nota**: No necesitas usar todos estos recursos. Elige 2-3 plataformas y enfócate en la práctica consistente. La clave es la constancia, no la cantidad de recursos.

¡Feliz aprendizaje! 🚀
