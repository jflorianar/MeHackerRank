# 📚 Ejercicios

Esta carpeta contiene todos los ejercicios resueltos de HackerRank organizados por categoría.

## 📂 Estructura

### `algorithms/`
Problemas relacionados con algoritmos clásicos:
- `warmup/` - Problemas de calentamiento
- `implementation/` - Implementación de algoritmos básicos
- `sorting/` - Algoritmos de ordenamiento
- `search/` - Algoritmos de búsqueda
- `dynamic-programming/` - Programación dinámica
- `greedy/` - Algoritmos greedy
- `graph-theory/` - Teoría de grafos

### `data-structures/`
Problemas de estructuras de datos:
- `arrays/` - Arrays y matrices
- `linked-lists/` - Listas enlazadas
- `trees/` - Árboles (binarios, BST, AVL, etc.)
- `stacks-queues/` - Pilas y colas
- `heaps/` - Heaps y colas de prioridad
- `hash-tables/` - Tablas hash y diccionarios

### `python/`
Track específico de Python en HackerRank:
- `introduction/` - Introducción a Python
- `basic-data-types/` - Tipos de datos básicos
- `strings/` - Manipulación de strings
- `sets/` - Conjuntos
- `collections/` - Módulo collections
- `itertools/` - Módulo itertools

### `mathematics/`
Problemas matemáticos:
- `fundamentals/` - Fundamentos matemáticos
- `number-theory/` - Teoría de números
- `combinatorics/` - Combinatoria
- `algebra/` - Álgebra
- `geometry/` - Geometría

## 🚀 Cómo Añadir un Nuevo Ejercicio

1. Identifica la categoría correcta
2. Crea un archivo con nombre descriptivo (snake_case)
3. Usa la plantilla en `/template.py`
4. Completa toda la documentación
5. Haz commit con el formato: `Add: [Categoría] Nombre - Dificultad`

Para más detalles, consulta [`CONTRIBUTING.md`](../CONTRIBUTING.md) en la raíz del proyecto.
